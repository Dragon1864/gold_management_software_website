Gold Loan Management System

A lightweight desktop application designed for gold loan businesses to efficiently manage customer records, loans, settlements, ledgers and business statistics.

About the Software

Gold Loan Management System (GLMS) is a Windows desktop application developed to simplify the daily operations of gold loan businesses. It provides an easy-to-use interface for maintaining loan records, releasing pledged gold, tracking settlements and monitoring business performance.

Key Features

  • ✔ Gold Loan Entry
  • ✔ Gold Release Management
  • ✔ Master Ledger
  • ✔ Dashboard with Business Statistics
  • ✔ Search, Filter & Sorting
  • ✔ Gold Valuation Calculator
  • ✔ Excel Export
  • ✔ Automatic Software Updates
  • ✔ Lightweight SQLite Database

System Requirements

  • Operating System: Windows 10 / Windows 11
  • RAM: 2 GB or higher
  • Disk Space: Less than 100 MB
  • Internet: Required only for software updates
